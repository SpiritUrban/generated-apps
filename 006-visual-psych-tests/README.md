# Mental Topography (Visual Psychological Tests)

A non-verbal, interactive psychological testing application built with React, Vite, and Framer Motion.

## Installation

```bash
npm install
```

## Running the Project

```bash
npm run dev
```

Then open `http://localhost:5173` in your browser.

## Features

- **Non-verbal Testing**: 3 distinct visual tests measuring control, risk tolerance, stability, and internal tempo.
- **Interactive UI**: Drag, click, and explore. No text forms.
- **Local Storage**: Results are saved locally in your browser.
- **Visual Analytics**: Polygon radar chart visualization of your traits.

## Tech Stack

- React + TypeScript
- Vite
- Framer Motion (Animation)
- TailwindCSS (Styling)
- Lucide React (Icons)
