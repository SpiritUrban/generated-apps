Antigravity



Создай веб-приложение с в новой папке название которой начинается с 005 психологическими визуальными тестами.
Это НЕ текстовые опросники и НЕ вопросы с вариантами ответов.

Цель:
Создать интерактивную систему тестирования, где человек:
- взаимодействует с визуальными объектами
- кликает / тянет курсором / выбирает позицию в пространстве
- не чувствует, что его «тестируют»
- получает результат на основе поведения, а не слов

Формат тестов:
1) Основа — 2D-плоскости (canvas или SVG).
2) Пользователь:
   - кликает в точку
   - тянет курсор
   - выбирает область
   - двигает объект
3) Вопрос формулируется образно, без явной психологии.
   Примеры:
   - «Где тебе спокойнее находиться?»
   - «Куда бы ты сместился, если нужно сохранить контроль?»
   - «Выбери точку, где напряжение минимально»

Примеры тестов (обязательно реализовать минимум 3):
1) Плоскость «Контроль ↔ Свобода» × «Безопасность ↔ Риск»
   — пользователь кликает точку.
2) Плоскость с движущимися объектами
   — пользователь выбирает, за каким объектом следить.
3) Перетаскивание маркера в зону комфорта
   — время, траектория и колебания фиксируются.

Что фиксировать:
- координаты кликов
- время реакции
- траекторию движения мыши
- колебания / возвраты
- последовательность действий

Обработка:
- каждый тест даёт числовые параметры (0..1 или -1..1)
- параметры сохраняются локально
- на основе набора параметров формируется профиль

Результат:
- визуальный отчёт (график / карта / схема)
- краткое текстовое описание состояния:
  (например: «ориентация на контроль», «высокая тревожность», «адаптивность»)
- без диагнозов, без клинических терминов

Технологии:
- Frontend: Vite + React + TypeScript
- Визуализация: Canvas API или SVG
- Хранение: localStorage (без сервера)
- Всё работает офлайн

Структура:
- Экран выбора теста
- Экран прохождения (fullscreen, минимум UI)
- Экран результата
- Возможность пройти тест заново

Важно:
- Интерфейс минималистичный, спокойный
- Никакой перегрузки текстом
- Акцент на ощущение игры / исследования
- Код должен быть рабочим, не демо

Выход:
1) Полная структура проекта
2) Готовый код всех компонентов
3) Инструкция запуска
