  Создай прототип RTS-игры в стиле StarCraft, но без копирования IP.
Цель — играбельный минимальный RTS-прототип в браузере.

Требования:

1) Технологии
- Frontend only
- Vite + TypeScript
- Canvas API (без Phaser и без движков)
- Всё работает локально и офлайн

2) Вид игры
- Top-down 2D
- Карта — сетка (tile-based)
- Камера фиксированная
- Простая графика: прямоугольники, круги, цвета

3) Сущности
- Unit:
  - id
  - position (x,y)
  - hp
  - speed
  - attackRange
  - attackDamage
  - owner (player | enemy)
- Building:
  - base (производит юнитов)
  - resourceExtractor
- Resource:
  - кристаллы / энергия (на карте)

4) Игровая логика
- Игрок может:
  - выделять юнитов рамкой
  - отдавать команды move / attack
  - строить базу
  - добывать ресурсы
  - производить юнитов
- Враг (AI):
  - простой FSM:
    - разведка
    - сбор ресурсов
    - атака волнами
- Победа:
  - уничтожение базы врага
- Поражение:
  - потеря своей базы

5) Управление
- ЛКМ:
  - выделение юнита / рамка
- ПКМ:
  - команда движения или атаки
- Кнопки UI:
  - Build unit
  - Build extractor

6) Архитектура
- game/
  - Game.ts (loop)
  - World.ts
  - Unit.ts
  - Building.ts
  - Resource.ts
  - AIController.ts
- render/
  - renderWorld()
  - renderUnits()
  - renderUI()
- input/
  - mouse.ts
  - selection.ts

7) Game Loop
- requestAnimationFrame
- update(dt)
- render()

8) Минимальный UI
- Панель ресурсов
- Панель выбранного объекта
- Кнопки действий

9) Качество
- Код должен запускаться сразу
- Без заглушек
- Комментарии по ключевой логике
- Не демо — а базовая игра, в которую можно играть 5–10 минут

Выход:
1) Структура проекта
2) Полный код файлов
3) Инструкция запуска
