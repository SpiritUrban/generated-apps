Ты — Codex. Создай одностраничное веб-приложение “DEV-MIND JS” — JS-тренажёр микро-уроков и микро-задач, который учит не синтаксису, а мышлению разработчика.

Критерий успеха:
- Запускается локально (npm/pnpm install + dev)
- Работает без сервера, все данные в localStorage
- Есть минимум 12 микро-уроков и 12 микро-задач (с авто-проверкой)
- Есть режим “Учусь думать как разработчик” с упражнениями на мышление
- Есть слой состояния (фокус/усталость/напряжение 0..5) и адаптация выдачи

Технологии:
- Vite + React + TypeScript
- Без внешних UI-библиотек
- Встроенный редактор: обычный <textarea>, но с моноширинным шрифтом и табами
- Выполнение кода задач: через Function() в безопасном контейнере (ограничить доступ: не давать window/document; вызывать только пользовательскую функцию)
- Проверка: набор тестов (input -> expected), сравнение глубокое для массивов/объектов

Структура приложения (экраны в одном SPA):
1) Home/Dashboard:
   - прогресс (сколько уроков/задач сделано)
   - “Продолжить”
   - быстрый выбор: Lesson / Challenge / DevMind
   - блок состояния: 3 слайдера (focus/fatigue/tension) + кнопка “Сохранить состояние”

2) LessonView (микро-урок):
   - 1 концепт за раз (3–7 предложений)
   - 1 “правило/инвариант”
   - 1 мини-вопрос на размышление (без вариантов)
   - кнопки: “Понял”, “Повторить позже”
   - уроки должны быть про мышление: инварианты, границы, декомпозиция, именование, контракт функции, ошибки, тесты, сложность, побочные эффекты, состояние, идемпотентность, данные vs поведение

3) ChallengeView (микро-задача):
   - описание задачи (коротко)
   - “контракт” функции (имя, сигнатура, примеры)
   - поле кода (textarea) с заготовкой function solve(...) { }
   - кнопка “Run tests”
   - вывод: список тестов (pass/fail) + сообщение об ошибке
   - кнопка “Показать подсказку” (1–2 фразы)
   - кнопка “Показать решение” (доступно только после 2 неудачных попыток или по подтверждению)

4) DevMindView (мышление):
   - упражнения не про код, а про решения:
     - “Разбей задачу на шаги” (пользователь пишет пункты)
     - “Найди крайние случаи” (пользователь пишет 3–5)
     - “Сформулируй контракт” (входы/выходы/ошибки)
     - “Опиши тест-план” (минимум 5 тестов)
   - потом приложение показывает “эталонный чеклист” и оценивает полноту по простым эвристикам (кол-во пунктов, наличие слов: empty/null/edge/invalid/boundary, и т.п.)
   - сохранять ответы пользователя локально

Адаптация по состоянию (обязательно):
- если fatigue >= 4 или tension >= 4:
  - показывай более короткие уроки
  - предлагай DevMind-упражнения без кода
  - уменьшай количество тестов в задачах (например 4 вместо 8)
- если focus <= 2:
  - предлагай “разогрев”: очень простая задача/урок
- если focus >= 4 и fatigue <= 2:
  - можно давать сложнее (больше тестов, задача чуть длиннее)

Данные:
- Уроки и задачи хранить в виде массивов объектов в src/content/*.ts
- Прогресс:
  - completedLessons: string[]
  - completedChallenges: string[]
  - attemptsByChallenge: Record<string, number>
  - userState: { focus, fatigue, tension }
  - devMindNotes: записи ответов пользователя

Требования к контенту:
- 12 уроков (id, title, text, rule, prompt)
- 12 задач:
  - простые, но “мышление”: normalizeName, clamp, groupBy, memoize (упрощённо), safeGet, unique, parseKV, compareVersions (упрощённо), debounce (без таймеров можно имитацию), isPalindrome (но с edge cases), chunk, deepEqual-lite
  - у каждой: tests (inputs, expected), hint, solution

UI:
- минималистичный, аккуратный
- навигация сверху: Dashboard / Lesson / Challenge / DevMind
- отдельный блок “Состояние” всегда доступен (например в шапке)

Выход:
1) Дерево файлов
2) Полный код ключевых файлов: main.tsx, App.tsx, компоненты экранов, utils/testRunner.ts, utils/sandbox.ts, storage/progress.ts, content/lessons.ts, content/challenges.ts
3) Инструкции запуска
